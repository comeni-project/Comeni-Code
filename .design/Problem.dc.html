Counting reads, and counting molecules

Attached to A read is a sample, not the molecule. Solving it is what marks that node solid — reading it is not.
The problem

A FASTQ file records one read per four lines: an identifier, the sequence, a separator, and the quality string. Two reads may carry different identifiers and the same sequence — the sequencer saw the same letters twice, and nothing in the file says whether that was one molecule read twice or two molecules that happened to match.

Your dataset holds a small library. Count how many reads it contains, and how many distinct sequences appear among them.

Given
A FASTQ file of at most 50,000 reads, each at most 300 nt.
Return
Two integers separated by a space: the number of reads, then the number of distinct sequences.
Sample dataset
@r1 GATTACAGATTACAGATTACA + FFFFFFFFFFFFFFFFFFFFF @r2 CCTGAATCCTGAATCCTGAAT + FFFFFFFF:FFFFFFFFFFFF @r3 GATTACAGATTACAGATTACA + FFFF,FFFFFFFFFFFFFFFF
Sample output
3 2
Three reads. Two sequences — r1 and r3 are the same letters.
