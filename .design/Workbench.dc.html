The trick is to stop treating reads as units. Slide a window of width k along each read and record every substring it covers: these are the read’s k-mers.[1]

Two reads that overlap share k-mers, so overlaps can be found by looking k-mers up in a table instead of aligning reads to each other.[1] Every assembler since 2008 works this way.
