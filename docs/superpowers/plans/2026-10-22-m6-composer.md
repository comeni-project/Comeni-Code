# M6.5 The figure composer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A page per figure (Choose, Data, Describe) that edits the figure's file as a YAML
document in the browser, draws it as you type, runs every server check live and sends it to the
field, and saves once; the workbench's YAML box and `FigureAdder` go.

**Architecture:** The working copy is the file's **text**; a `yaml` Document parsed from it is
what sheets and the form edit, and every edit writes the text back, so Edit as YAML, the sheets
and the preview share one copy. A file has one reading: plain scalars that PyYAML and YAML 1.2
read differently are refused on both sides, the list of forms being data in `code-figures`
generated into the web. Every server check (`code_schema/figures.py` and the four kits) has a
TypeScript twin, held to `tests/fixtures/figures/cases.json` by both suites. Saves go through the
draft's one edit queue: `PUT /figures/{stem}`, then `PUT /blocks/{at}`; or one `POST /figures`
with `text`.

**Tech Stack:** Python 3.14, PyYAML, Django Ninja; React, TypeScript 7, vitest, `yaml@2.9.1`
(new, exact; published 2026-09-11, no dependencies).

**Spec:** `docs/superpowers/specs/2026-10-21-m6-composer-design.md` (M6CO.1–M6CO.7), #332.
Boards: https://claude.ai/artifact/JL1PkAjBQKv6o493XDgCoR (*S4 · Figure composer — Choose*,
*Data: a chart*, *Data: a flow with a problem*), generated by `.design/build_pages.mjs`
(`figureComposer`) as `.design/ComposerChoose.dc.html`, `ComposerChart.dc.html`,
`ComposerFlow.dc.html`.

## Global Constraints

- Routes: `/studio/drafts/:id/figures/:stem?block=<n>` (edit) and
  `/studio/drafts/:id/figures/new?at=<n>` (add); Studio's rail collapsed on both.
- The file is never regenerated: an edit changes only the nodes it touches; comments, key order,
  quoting and untouched lines stay byte for byte. The server stores the text as sent.
- One reading (operator, 2026-10-21, A): a plain scalar (value **or key**) matching a form in
  `code_figures/readings.json` is CS1023, message `<path>: \`<text>\` reads two ways; quote it`.
  The forms are written once, in that file; the web gets them generated into `schemas.ts`.
- Values the composer writes: numbers in plain decimal; a string whose plain form would read as
  anything but that string (in YAML 1.2 core or by a form above) is written double-quoted; no
  anchors or aliases.
- Problem shape in the browser: `{ code, path, message }`, the path as code-figures writes it
  (`data.edges[1].to`, `data.rows[3][1]`, `data.data.values[2].x`); file-level paths `component`,
  `alt`, `source`, `source.title`, `source.url`, a top-level key for CS1025, `""` for the whole file.
- Codes are never renumbered; CS1023's `says` widens to *"a figure file cannot be read, or reads
  two ways"*. Regenerate `docs/reference/diagnostics.md`.
- No new learner-facing behaviour; no model call; no request while typing.
- Web commands on Node 24; after any API change, export OpenAPI and `npm run api-types`; after
  `readings.json` changes, `npm run figure-types`.

## Review Focus

1. **A duplicate key** in a figure file (`alt:` twice): PyYAML keeps the last, the `yaml` package
   refuses; both must refuse with CS1023 at that key — `test_duplicate_key_is_refused` (Task 1) and
   the shared file case *a key twice* (Task 4).
2. **Typing `on`, `012` or `1e3` into a text cell** (a flow label, a table's text column): it must
   be written quoted and pass, not refused as two readings — `document.test.ts` *"a string that
   would read otherwise is written quoted"* (Task 3).
3. **A paste that does not fit the sheet** (more columns than keys, ragged rows, a quoted CSV
   field with a comma, a trailing blank line): extra cells dropped with a line saying how many,
   never a crash — `paste.test.ts` (Task 5).
4. **Edit as YAML left unparseable, then back to the sheets**: the sheets are replaced by the
   reason line, the text kept as typed, Save disabled — `ComposerPage.test.tsx` *"a file that
   does not parse keeps the text and hides the sheets"* (Task 6).
5. **A save refused by the server after the browser passed it** (a check that drifted, or a stale
   revision): the composer stays open with the copy as typed and the 422's problems in Checks —
   `ComposerPage.test.tsx` *"a refused save keeps the copy"* (Task 6).

### Task 1: One reading, on the server

**Files:** create `packages/code-figures/src/code_figures/readings.json`,
`packages/code-figures/src/code_figures/readings.py`; modify `code_figures/__init__.py`,
`packages/code-schema/src/code_schema/figures.py`, `code_schema/diagnostics.yml` (CS1023),
`apps/web/scripts/generate-figure-types.ts` (emit `TWO_READINGS`), `apps/web/src/figures/schemas.ts`
(regenerated); `tests/fixtures/figures/cases.json` (new `files` list); tests
`tests/figures/test_readings.py`, `tests/schema/test_figures.py`, `tests/figures/test_cases.py`.

**Interfaces (produced):**
- `readings.json`: `{"$comment": …, "forms": [{"name": str, "pattern": str}]}` — patterns valid
  in both Python `re` and JavaScript `RegExp`, anchored. Exactly these forms (derived 2026-10-22
  from PyYAML's resolver with `_Loader`'s constructors against YAML 1.2 core):
  - *a YAML 1.1 boolean*: `^(yes|Yes|YES|no|No|NO|on|On|ON|off|Off|OFF)$`
  - *a number only YAML 1.2 reads*: a 1.2 core int/float (`[-+]?[0-9]+`, `0o[0-7]+`,
    `0x[0-9a-fA-F]+`, `[-+]?(\.[0-9]+|[0-9]+(\.[0-9]*)?)([eE][-+]?[0-9]+)?`, `[-+]?\.(inf|Inf|INF)`,
    `\.(nan|NaN|NAN)`) that is not `[-+]?(0|[1-9][0-9]*)(\.[0-9]*([eE][-+][0-9]+)?)?`, written as
    one pattern with a negative lookahead;
  - *a merge key*: `^<<$`; *a value key*: `^=$`.
  `1:30`, `~`, `null`, `true`, `2024-01-02`, `1_000` read alike and stay allowed (a case pins
  each).
- `code_figures.readings.TWO_READINGS: tuple[Form, ...]`, `Form(name: str, pattern: re.Pattern[str])`;
  `two_readings(plain: str) -> str | None` (the form's name). Exported from `code_figures`.
- `code_schema.figures`: before constructing, compose the text with `_Loader` and walk the node
  tree; each plain (`style is None`) scalar, key or value, for which `two_readings` names a form
  is a CS1023 problem `f"{path}: \`{value}\` reads two ways ({name}); quote it"`; each key seen
  twice in one mapping is CS1023 `f"{path}: has {key} twice"`. Paths as Global Constraints
  (top-level keys bare: `data.mark`, `alt`). These problems return before any other check.
- `schemas.ts` gains `export const TWO_READINGS = [{ name, pattern }, …] as const;` from the
  same generator; the staleness test covers it.
- `cases.json` gains `"files": [{"name", "text", "codes"}]`; `about` rewritten to say `cases` are
  data through `figure_findings` (schema and kit) and `files` are whole files through
  `read_figure`.

- [ ] Tests: `test_readings.py` — each form's examples match and the allowed list does not;
  every pattern compiles; `test_figures.py` — `test_two_readings_refused` (`mark: on`, `x: 1e3` in
  a value row, a key `yes:`; each CS1023 with its path), `test_duplicate_key_is_refused`,
  `test_quoted_forms_pass` (`"on"`, `'1e3'`); `test_cases.py` — files run through `read_figure`,

- [ ] Run (fail): `uv run pytest tests/figures tests/schema/test_figures.py -q`.
- [ ] Implement; also the five fixture figures still read (`uv run pytest -q tests/schema`).

### Task 3: The YAML document layer

**Files:** `apps/web/package.json`, `package-lock.json` (`yaml` `2.9.1`, exact, dependency);
create `apps/web/src/figures/document.ts`, `document.test.ts`.

**Interfaces (produced):**
- `type Path = (string | number)[]`; `pathText(path: Path): string` (`["data","edges",1,"to"]` →
  `data.edges[1].to`) and `pathParts(text: string): Path`, inverse.
- `openFile(text: string): FigureDocument` — `parseDocument(text, { version: "1.2", schema:
  "core", merge: false, uniqueKeys: true, keepSourceTokens: true })`; `FigureDocument = { doc:
  Document; errors: { message: string; line: number }[]; value: unknown }`.
- `setAt(fd, path, value: string | number | boolean | null): string` — the new text. Number →
  plain decimal scalar; string → `QUOTE_DOUBLE` when its plain form would not read back as the
  same string (parse it plain with core schema, or `two_readings`-equivalent from
  `TWO_READINGS`), else left to the node's existing style; existing node edited in place.
- `insertAt(fd, path, item: unknown): string`, `removeAt(fd, path): string`,
  `moveAt(fd, path, to: number): string` (sheet rows).
- `lineOf(fd, path): number | null` — the 1-based line of the node at `path`.
- `plainScalars(fd): { path: Path; text: string }[]` — every plain key and value, for Task 4.

### Task 5: Sheets and the generated form

**Files:** create `apps/web/src/studio/composer/` — `sheets.ts` (+ test), `paste.ts` (+ test),
`fasta.ts` (+ test), `Sheet.tsx` (+ test), `SchemaForm.tsx` (+ test), `formable.ts` (+ test).

**Interfaces (produced):**
- `Column = { key: string | number; label: string; cell: "text" | "number" | "select" | "switch";
  options?: string[] }`; `SheetSpec = { title: string; path: Path; columns: Column[]; blank:
  unknown }` (`blank` is a new row).
- `sheetsOf(component: Component, data: unknown): SheetSpec[]` — table: `columns` (name, type
  select of the schema's enum, unit, decimals), `rows` (columns are the table's columns by index,
  `cell` from each column's type); chart: `data.values`, columns the keys rows use in first-seen
  order; flow: `nodes`, `edges`, `groups`; sequence-track: `features`. Column cells read from the
  item schema in `SCHEMAS` (enum → select, integer/number → number, boolean → switch, else text).
- `formable(component, value): string | null` — why the form cannot hold it, else null: *does
  not parse*, *a layered chart: edit it as YAML*, *a key the form does not show: <path>*.
- `parsePaste(text: string, keys: string[]): { header: boolean; rows: string[][]; dropped:
  number }` — tab-separated if any tab, else CSV with `"` quoting; first row is a header when its
  cells equal the keys (case-insensitive, any order — then rows are reordered to the keys); a
  trailing blank line ignored; cells past the last column dropped and counted.
- `fastaLetters(text: string): string` — header lines (`>`) dropped, whitespace removed.
- `<Sheet spec rows onCell(path, value) onInsert(path, at) onRemove(path) onMove(path, to)
  onPaste(path, at, text) problems />` — a `<table>`; each cell's control carries
  `data-path={pathText(cellPath)}`; a problem's path marks its cell (`aria-invalid`) .
- `<SchemaForm component value onSet(path, value) />` — every non-sheet key of the schema: enum →
  select, string → input, integer/number → number input, boolean → switch, object → fieldset,
  `oneOf` → a switch between branches by JSON type (chart `mark`: a name, or an object with
  `type`, `point`, `interpolate`, `opacity`); the chart's encoding offers one row per channel
  with `field` a select of the values' columns. Only allowlisted keys are offered. Every control
  carries `data-path`.
