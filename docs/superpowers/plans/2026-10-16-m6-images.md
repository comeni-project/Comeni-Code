# M6.3 Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Images stored in the node's folder, placed by `:::{image}`, recorded in `node.yaml`,
added by upload or from Wikimedia Commons, reviewed, landed and drawn on the page.

**Architecture:** `code-schema` reads the block, the record and the files (`code_schema/images.py`:
records, formats by magic bytes, licences); `parse_node_files` takes the folder's images as
`{file: bytes}`. Studio keeps a draft's images content-addressed (`Asset`) and each revision names
them; landing writes blobs; the index keeps `NodeImage`; two routes serve the bytes. A
`studio/commons.py` client fetches a Commons file and its credit. The web draws *Figure N*.

**Tech Stack:** Python 3.14, Django Ninja (multipart upload), `requests` (Commons), Postgres
`bytea`, React, vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-m6-images-design.md` (M6IM.1–M6IM.6), #330.

## Global Constraints

- Folder: `<node>/images/<name>.<png|jpg|jpeg|webp>`; names `^[a-z0-9]+(-[a-z0-9]+)*\.(png|jpe?g|webp)$`.
- Formats by first bytes: PNG `\x89PNG\r\n\x1a\n`, JPEG `\xff\xd8\xff`, WebP `RIFF....WEBP`;
  the extension must agree. SVG and everything else refused. At most 2 MB (2 * 1024 * 1024).
- Record fields, all required: `file`, `alt` (one sentence, ≤ 300), `author` (one line),
  `source` (an https URL, or `own work`), `licence` (canonical: `CC0 1.0`, `Public domain`,
  `CC BY <v>[ <port>]`, `CC BY-SA <v>[ <port>]`, v in 1.0, 2.0, 2.5, 3.0, 4.0).
- Commons: public-domain flavours → `Public domain`; several licences → the first accepted in
  CC0, public domain, CC BY, CC BY-SA order; width 1600, then 1000 if over 2 MB.
- Codes: block and placement in CS04xx (body); the record in a new CS02xx-adjacent run if the
  resources band has room, else the next free band (check `diagnostics.yml` bands; never renumber).
- `code-schema` stays pure: the Commons client lives in `apps/api`; licence mapping from Commons
  short names is pure and lives in `code_schema.images`.
- The follower's tarball cap: 500 MB.
- Web commands in `node:24-alpine`; tests never call Commons (a recorded answer).

## Review Focus

1. An image file present in `images/` but no record (or a record but no file): refused by name, not a crash.
2. A file renamed `.png` that is a JPEG: refused (the extension must agree with the bytes).
3. Replacing an image's bytes under the same name in a draft: a new revision, a new sha256, the
   review key changed.
4. An index built before this change: nodes without images read and serve as before.
5. A Commons link to a file page with an accepted and an NC licence: the accepted one is taken.

### Task 1: The format — block, record, files, licences

**Files:** Create `packages/code-schema/src/code_schema/images.py`; modify `blocks.py` (`Image`
block: `file`, `caption`; parser, writer, codec; out of `_LATER`), `node.py` (`IMAGE_FIELD =
"images"`, `Node.images: tuple[ImageRecord, ...]`, `parse_node_files(..., images: Mapping[str,
bytes] | None = None)`, `read_node` reads `images/`), `exam.py` (stems allow `Image`),
`writer.py` (`images` after `resources`), `__init__.py`, `diagnostics.yml`; tests
`tests/schema/test_images.py`, `test_public_api.py`.

**Interfaces:**
- `ImageRecord(file: str, alt: str, author: str, source: str, licence: str)` (frozen).
- `sniff(data: bytes) -> str | None` → `"image/png" | "image/jpeg" | "image/webp" | None`.
- `canonical_licence(text: str) -> str | None`; `licence_from_commons(short_names: Sequence[str]) -> str | None`;
  `deed_url(licence: str) -> str | None`.
- `image_problems(records, images: Mapping[str, bytes], placed: Collection[str], *, file: str, where: str) -> list[Problem]`.

- [ ] Tests: the block round trip (`:::{image} a.png` + caption); a caption is required; the
  record parses and writes back; each refusal (unplaced record, unrecorded file, missing file,
  bad name, wrong bytes for the extension, SVG bytes, 2 MB + 1, a missing field, an NC licence);
  `canonical_licence` on `CC BY-SA 3.0 de`, `CC0`, `cc-by-4.0`; `licence_from_commons(["CC BY-NC
  2.0", "CC BY-SA 3.0"])` → `CC BY-SA 3.0`, `["PD-US"]` → `Public domain`; `read_node` on a folder
