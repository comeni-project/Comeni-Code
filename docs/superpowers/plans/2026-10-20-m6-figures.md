# M6.4 Figures, the ground — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Figures as library components filled with data: `figures/<stem>.yaml` in the node's
folder, placed by `:::{figure}`, a try's `figure:` or an exam stem; the four general kits
(`table`, `chart`, `flow`, `sequence-track`) checked by a new pure package and drawn in the
identity; charts made safe; edited as YAML in the workbench; reviewed, landed and indexed. Also an
image's `source` made optional (#360).

**Architecture:** `code-figures` holds each component's JSON Schema (data) and its checks, and a
validator for the schema subset; it returns findings with a code and a JSON path. `code-schema`
reads `figures/`, parses each file into a `FigureFile` on `Node.figures`, and calls `code-figures`,
so every reader refuses by one path. A draft keeps figures as text (`Revision.figures`); the
index keeps `NodeFigure`; the page joins blocks to figures by stem, as images. The web validates
again with a TypeScript twin over the same schemas and the same cases, then draws in our SVG
(dagre for the flow's layout, Vega for charts, lazily and locked down). nginx sends a CSP.

**Tech Stack:** Python 3.14, PyYAML, Django Ninja, Postgres jsonb; React, TypeScript 7, vitest,
`json-schema-to-typescript` (have it), `@dagrejs/dagre`, `vega`, `vega-lite`, `vega-interpreter`.

**Spec:** `docs/superpowers/specs/2026-10-20-m6-figures-design.md` (M6FG.1–M6FG.7), #331; #360.
Boards: https://claude.ai/artifact/4TEYrit2cBWGcJJmXrKAyw (*L5 · Figures — the general kits*,
*S3 · Workbench — a figure block*), generated by `.design/build_pages.mjs` (`figureKits`,
`benchFigure`).

## Global Constraints

- Folder: `<node>/figures/<stem>.yaml`; stem `^[a-z0-9]+(-[a-z0-9]+)*$`; a file at most 64 KB
  (64 * 1024 bytes). Top-level keys exactly `component`, `alt` (required), `data`, `source`
  (optional: `{title, url?}`, `url` an `https://` link).
- Placement: `:::{figure} <stem>` + a one-paragraph caption (required); try question key
  `figure: <stem>`; exam stems take figure blocks. One file may be placed more than once; a file
  nothing places is refused.
- Codes: the block's own problems in CS04xx (next free after the image block's); everything else
  in a **new band CS1000–CS1099, concern `figures`** (add it to `bands:`). Never renumber.
- `code-figures` imports only `__future__`, `collections.abc`, `dataclasses`, `json`, `pathlib`,
  `re`, `typing`; it never imports `code_schema`. `code-schema`'s allowlist gains `code_figures`.
- Bounds: table ≤ 8 columns, ≤ 50 rows; chart ≤ 2 000 rows, ≤ 20 columns, a string cell ≤ 200,
  ≤ 4 layers; flow ≤ 20 nodes (label ≤ 40), ≤ 40 edges (label ≤ 24), ≤ 4 groups; track sequence
  ≤ 120 letters or `length` ≤ 100 000, ≤ 30 features, 1-based inclusive.
- Chart allowlist exactly as M6FG.4 layer 1 lists it; no `url`, `transform`, `params`, `signal`,
  `expr`, `config`, `usermeta`, `$schema`, `width`, `height`, `autosize`, `title` (top), `scheme`,
  `range`, colour `value`, `href`, `image` mark.
- Schemas only widen once content uses them (a narrowing is a new component name).
- Studio keeps a figure's text as written; nothing canonicalises it.
- Colour: one series neutral ink; several take `series` from `tokens.json` (light and dark);
  teal, blue, amber, red are never series colours.
- CSP (nginx `location /` only): `default-src 'self'; script-src 'self'; style-src 'self'
  'unsafe-inline'; img-src 'self'; connect-src 'self'; font-src 'self'; frame-src
  https://www.youtube-nocookie.com; object-src 'none'; base-uri 'self'; frame-ancestors 'none'`.
- Web commands on Node 24. Tests never read the real content repository.

## Review Focus

1. A YAML figure that parses to a non-mapping (a list, a bare string, `null`, an empty file): one
   refusal with its code, never a crash — `test_figure_not_a_mapping` in Task 3.
2. A chart whose `values` are sparse (a field in some rows only, as Vega allows): the field is a
   column if any row has it, and its present values must match its `type`; never refused for the
   gaps — `test_chart_sparse_rows` in Task 2.
3. A figure placed in both the body and a try question, then removed: every placement goes with it
   and the save succeeds (#356's shape) — `test_remove_figure_everywhere` in Task 4.
4. An index built before this change (no `NodeFigure` rows, figures absent from the payload): the
   page reads and draws as before; the web's `Figure` treats a missing record as the fallback —
   `test_node_without_figures_reads` (Task 5) and `Figure.test.tsx` "a block whose record is
   missing" (Task 7).
5. A YAML number the browser cannot hold exactly (`1e400`, a 30-digit integer) in chart or table
   data: refused in Python as out of range (finite and |x| < 1e15), so Python and the browser agree —
   `test_numbers_must_be_finite_and_bounded` in Task 1.

### Task 2: `code-figures` — the validator, the registry and the four kits

**Files:** create `packages/code-figures/` (`pyproject.toml`: no dependencies; `src/code_figures/
__init__.py`, `findings.py`, `schema.py`, `registry.py`, `table.py`, `chart.py`, `flow.py`,
`track.py`, `schemas/{table,chart,flow,sequence-track}.json`); `tests/guards/purity.py` (allowlist
above); `tests/fixtures/figures/cases.json`; tests `tests/figures/test_schema.py`,
`test_table.py`, `test_chart.py`, `test_flow.py`, `test_track.py`, `test_registry.py`.

**Interfaces (produced):**
- `Finding(code: str, path: str, message: str)` (frozen). Paths start at `data`:
  `data.encoding.y.field`, `data.rows[3][1]`.
- `schema.validate(schema: Mapping[str, object], value: object, path: str = "data") -> list[Finding]`
  — the subset `type`, `properties`, `required`, `additionalProperties: false`, `items`, `enum`,
  `const`, `pattern`, `minimum`/`maximum`, `maxItems`, `maxLength`, `oneOf`, `$ref` to `$defs`.
  Unknown key → CS1002 (*not allowed*); wrong type, enum, pattern, const → CS1003; a bound → CS1004.
  Numbers: `bool` is never a number; a number must be finite with |x| < 1e15 (CS1003).
- `registry.COMPONENTS: Mapping[str, Component]`, `Component(name: str, schema: Mapping[str,
  object], check: Callable[[Mapping[str, object]], list[Finding]], derive: Callable[[Mapping[str,
  object]], dict[str, object]], starter: Mapping[str, object])`; schemas loaded from `schemas/` by
  `pathlib` relative to the module.
- `figure_findings(component: str, data: object) -> list[Finding]`: CS1001 for an unknown
  component; else schema, and the component's `check` only when the schema passed.
- `derived(component: str, data: Mapping[str, object]) -> dict[str, object]`.
- `CODES: frozenset[str]` — every code the package can emit (CS1001–CS1011).
- Check codes: CS1005 a chart field that is no column; CS1006 a field's values not of its `type`
  (quantitative → numbers, temporal → ISO `YYYY-MM-DD[THH:MM[:SS]]`); CS1007 a flow edge or
  node `group` naming nothing; CS1008 a duplicate id; CS1009 a feature out of bounds
  (`start > end`, `end > length`); CS1010 a letter outside the alphabet (`dna` ACGTN, `rna` ACGUN,
  `protein` the 20 + X, case-insensitive); CS1011 a table row with the wrong number of cells or a
  cell of the wrong type.
- Track `derive` → `{"lanes": [int, ...]}`, one per feature in order, first fit by start.
- `starter` per kit: the smallest valid data (a 2×2 table; a 3-row bar chart; two nodes, one edge;
  a 20-letter DNA sequence with one exon).

- [ ] Tests: each schema keyword accepted and refused with its code and path; `cases.json` (each
  case `{component, data, codes: [...]}`, valid ones with `codes: []`) all pass in Python; each
  kit's own checks; `test_chart_sparse_rows`; `test_numbers_must_be_finite_and_bounded`; every
  forbidden chart key in the constraint list refused by path (`data.encoding.href`,
  `data.data.url`, `data.transform`, `data.params`, `data.config`, `data.mark.type: image`);
  lanes for overlapping features; each `starter` passes; the purity guards pass with the new
  package and fail on a planted `import requests` (watched failing).
- [ ] Run (fail) → implement → `uv run pytest tests/figures tests/guards -q`, `uv run mypy` →
  commit `feat(figures): code-figures, its validator and the four kits (#331)`.
