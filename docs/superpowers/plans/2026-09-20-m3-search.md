# M3 part 2 — finding a target without AI: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** typed words become ranked candidate goals, through a pure function, a command and an
endpoint, with no model involved.

**Architecture:** `code_weaver.find` ranks `Target`s (id, title, claim) by word matching;
`code-weaver find` feeds it from files through `code-schema`, and `GET /api/search` feeds it from
the index in one query. The caller builds the cards.

**Tech Stack:** Python 3.14, Django 6.1, django-ninja, Postgres 18 in Compose, vitest for the web
type check.

**Spec:** [`docs/superpowers/specs/2026-09-20-m3-search-design.md`](../specs/2026-09-20-m3-search-design.md)

## Global Constraints

- **`code-weaver` stays pure.** Its allowlist in `tests/guards/purity.py` is
  `__future__`, `argparse`, `code_schema.content`, `code_schema.node`, `collections.abc`,
  `dataclasses`, `heapq`, `pathlib`, `re`, `sys`, `typing`. **`re` must be added** — that is the
  one reviewed allowlist change this part makes, and `unicodedata` is **not** added.
- **`find` never raises.** Bad input gives an empty `Found`, not an exception.
- **Determinism:** the same targets and words give the same order, in any process.
- Exit codes: 0 fine, 1 the content is wrong, 2 the command was used wrongly (M2P3.4).
- Tests never read `../comeni-code-content` (R1); everything runs on `tests/fixtures/salmon/`.
- Conventional Commits with a body ending `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- Never commit to `main`; the branch is `m3-part-2-search`.

- [ ] **Step 3: Write `find.py`**

```python
_WORDS = re.compile(r"[a-z0-9]+")
ID, TITLE, CLAIM = 3, 2, 1


def _words(text: str) -> tuple[str, ...]:
    found = tuple(_WORDS.findall(text.casefold()))
    kept = tuple(word for word in found if word not in STOP_WORDS)
    return kept or found  # a query of only stop words keeps them


def _hits(word: str, among: tuple[str, ...]) -> bool:
    if len(word) == 1:
        return word in among
    stem = word[:-1] if len(word) > 3 and word.endswith("s") else word
    return any(other.startswith(stem) for other in among)
```

Score each target: for every query word take the best field it hits, add the id and title
bonuses, then sort by `(-matched, -score, title.casefold(), id)`.
