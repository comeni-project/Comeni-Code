# Working notes

How the project got here, and what is true now.

## What is here

**[`now.md`](now.md)** — what is true today, by topic, each line citing the entry it came from.
**Read this first.**

**[`journal/`](journal/)** — one entry per working session: what changed, what was decided and
rejected, what is next, and what a fresh reader would get wrong. Entries not yet folded into
`now.md` sit at its top level; compacted ones are in `journal/archive/`.

**[`compaction.md`](compaction.md)** — how a journal entry becomes lines in `now.md`.

**[`research/`](research/)** — studies that decisions were built on, kept whole so specs can cite
them.

## The one rule

**Entries are append-only.** A correction goes in `now.md` or a later entry, never by editing an
earlier one. An archived entry may name a file that a later change removed; holding provenance to
the present tense would defeat the point of keeping it.

If you want to know what has been decided and why, that is the [specs](../superpowers/specs/).
