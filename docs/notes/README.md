# Working notes

**Provenance, not documentation.** These pages record how the project got here. They are dated,
they were true when written, and they are not maintained against the design or the code.

If you want to know what has been decided, that is the [specs](../superpowers/specs/). If you want
to know how and in what order it was reached, it is here.

## What is here

**[`journal/`](journal/)** — one entry per working session: what changed, what was decided and
rejected, what is next, and what a fresh reader would get wrong. Newest first.

**[`research/`](research/)** — studies that decisions were built on, kept whole so specs can cite
them.

## The one rule

**Entries are append-only.** A correction goes in a later entry, never by editing an earlier one.
A status page silently goes stale and nobody can tell how stale; a dated entry never claimed to be
current, only true on its date, and it still is.

## What this is not

Not a place to look things up. An entry may name a file that a later change removed; holding
provenance to the present tense would defeat the point of keeping it.
