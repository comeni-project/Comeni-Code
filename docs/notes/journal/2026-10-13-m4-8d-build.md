## Decisions, and why

In the spec (M4P.1–M4P.8) and its notes from the build. The rulings made while building:

- Web commands run natively: the host now has Node 24 (`node_modules` reinstalled for it).
- Options and their controls are lettered (*Option A*), as the board letters them.
- `BOX` and `LABEL` live in `bench.ts`, so the answer and try editors do not import each other.
- A row's label is *title, kind, state*; `renderPool` lives in `examKit.tsx` (Biome forbids
  exports from tests).
- The stem uses the page's fields, not `BlockEditor`; a closed draft disables the editor with one
  `<fieldset disabled>`; no selection opens the first question; deleting a stem block moves focus
  first, as removing an option does.
- The pool's tests answer the checklist GET, because a save waits for Checks to be asked again.
- Left from the board: the header's *Exam pool · n of m approved* tag (the header is every tab's;
  the count sits atop the list) and the level as a tag (a select here); scores, *Draft a question
  with AI*, *Variants*, figure and other stem blocks, *Figure interaction* and *History* are later
  phases (M4P.1).
