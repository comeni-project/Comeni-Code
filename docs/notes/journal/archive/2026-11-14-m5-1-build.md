## Decisions made, and why

- **A None key is not "no key" to LiteLLM**: it fills it from the host's `OPENAI_API_KEY`. So a
  keyless hosted connection is refused before LiteLLM (CA0400), other keyless routes send the
  placeholder `none`, and only `chatgpt/` routes pass None. The spec was corrected.
- **Code refreshes the ChatGPT token itself**, under a Redis lock with an atomic write, because
  LiteLLM's `_refresh_tokens` writes `auth.json` in place and its login blocks inside a call. The
  private methods still used are pinned by `test_ai_litellm_private.py`.
- **A self-hosted endpoint is stored ending in `/v1`, its models offered as `openai/<id>`.**
  Rejected: `ollama_chat/` names, which tie the connection to one server.
- **Priced is said by the API**, not guessed by the page from a null cost: a null cost was read as
  *plan* and mislabelled local calls.
