## Decisions, and why

All are in the spec, with what was rejected:

- **The pool is `exam.yaml`, not an `exam:` field** (M4E.1). Everything in the file stays off the
  page, so the rule is about one file.
- **Composition, not a class tree** (M4E.2). The operator first suggested a superclass. Answer kind
  and pool are two independent axes, and a tree multiplies one of them.
- **Exam answers are not a secret in v1** (M4E.6). The operator's point: the content repository is
  public, and Code teaches rather than certifies. The "no answer leaves the API" rule and its test
  were dropped. A supervised institutional mode would reopen it.
- **Warnings now, not deferred** (M4E.4). Deferring was recommended, but the operator preferred not
  to leave rules to be remembered, and the mechanism does not depend on M4.4 or #102.
- **The bound is 40, a sanity check, not a target** (M4E.3, M4E.7). The operator: a small cap means
  repeated questions; sampling is the exam builder's job.
