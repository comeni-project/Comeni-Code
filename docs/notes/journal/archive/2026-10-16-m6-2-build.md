## Decisions, and why

- **KaTeX in strict mode inside a `try`**, not `throwOnError: false`: an unknown command is drawn
  in KaTeX's red rather than marked as an error, so only strict mode lets the page fall back to
  plain source.
- **The renderer guarantees the invariants itself** (no link, no markup, no colour, bounded size),
  whatever the schema check misses; the check is there so authors learn of a slip before review.
- **One shared case table for the formula rule**: the Python finder is a port, and a port drifts;
  the table is generated from remark-math, never written by hand.
- **The worked example keeps its title in the panel** where the board draws a bare code panel
  (#347 records it).
