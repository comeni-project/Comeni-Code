## Decisions, and why

- **One save per image change**: a record must be placed and a placement recorded, so adding is
  file + record + block, and removing is all three, on the page and in every stem.
- **A new image never replaces another**: a taken name gets the next free one.
- **The author of a Commons file** is its `Attribution`, else its `Artist`, else its uploader;
  CC BY needs a name, and Commons does not always give an artist.
- **Commons is trusted only as far as its host**: images come from `upload.wikimedia.org`, without
  redirects, streamed and capped.
- **The exam stem editor does not add images yet** (#351): the format and API take them.

## Traps

- **Ninja matches routes in the order they are registered**: a fixed path (`/commons`,
  `/images/commons`) goes before the `{param}` route it would otherwise fall into.
- **`curl -I` sends HEAD**, which a GET route answers with Django's HTML; check headers with a GET.
- **Commons forbids NC files**, so the NC refusal can only be walked against the stub.
