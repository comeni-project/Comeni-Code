## M6 in parts

Each part is its own spec, plan and pull request (R5). Screens get boards first; S4 Figure
composer has one, S5 Problem builder and the learner's problem (L6) do not.

| Part | What |
|---|---|
| **M6.1** linked drafts | verify, the checklist and a landing batch see open drafts as nodes, so linked new nodes are written together and land as one pull request |
| **M6.2** math and example | the `math` (a formula that parses) and `example` (a worked example) blocks: format, index, Node page, workbench |
| **M6.3** images | the `image` block: alt text, caption, author, source, licence, refused without them; where the file lives and its size limit; adding one in the workbench |
| **M6.4** figures, the ground | `code-figures` (pure): a component's data schema and checks; the `figure` block in text and in `try`; the first general kits (`table`, `chart` as Vega-Lite, `flow`, `sequence-track`) drawn in the identity |
| **M6.5** the figure composer | S4, from its board: choose, data, interaction, describe, preview, checks |
| **M6.6** domain figures | the de Bruijn components (`read-tiling`, `kmer-window`, `kmer-graph`, …) and figure-interaction answers, computed by the component, in try and exam questions |
| **M6.7** problems, the ground | `code-problems` (pure): seeded generators and checkers as library components filled with parameters, never per-problem code; the `problem` block (Given/Return, sample, rung, misconceptions); the 20-seed self-test |
| **M6.8** problem builder and the learner's problem | S5 and L6, boards first: building one in Studio; a dataset per learner, one answer, feedback from misconceptions |
| **M6.9** M6's close | the de Bruijn page end to end in the fixtures, its problem and its figure exam question across 20 seeds (*done when*); journal and compaction |

The order: linked drafts first, because it is small and every later part's walk writes more than
one node; the simple blocks before figures; figures before problems, since a problem's sample
and the exam's figure answers lean on components.
