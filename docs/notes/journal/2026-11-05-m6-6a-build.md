## Decisions made, and why

- **The k-mer graphs lay out by the boards' rule, not dagre's rows** (`graphLayout.ts`). dagre
  gives each k-mer its column (its ranks, which survive a cycle); the main line (a path, the
  k-mers the reads agree on, or the first read's) takes one row, and each run off it a row of its
  own, the first below, the next above. The plan said "dagre, as the flow is"; dagre's ordering
  pulled the solid AGC up beside the bubble's CAG, and its `align` options put the tip in the main
  row, which tells the error's story wrongly. Rejected: edge weights (dagre's placement ignores
  them), first-fit rows (put the tip beside the bubble).
- **The boards spend no colour but the path's** (W10). The redraw took teal off the tiling's
  reads, the window's bars and the conventions' arrows, not only the tiling and bubble the plan
  named; prose inside the board's drawings moved to their captions, since a component draws none.
- **A short list of numbers of a fixed length is a row of inputs in the form** (`isPair`:
  `minItems == maxItems ≤ 4`, number items). Without it every domain file with a `path` or a
  `range` opened as YAML only. One rule, not a case per kit.
- **What is computed is said from the data, only while the data checks**, not from the working
  copy's last good figure: a new figure's empty alt text would otherwise hide it.
- **FASTA parsing sits in `fasta.ts`** beside `fastaLetters`, not in `paste.ts` as the plan said:
  one file for FASTA, both its uses.
- **The green-path try follows spell-the-path in `node.yaml`**, the order the body asks them;
  questions come back in the file's order.
- **The edit tests find kmers-per-read and shared-unitig by their blocks**, not by place, so the
  next block added to the fixture moves nothing there.
- **A drawing keeps three quarters of its width** (#402; letters at 11 px or more) and a framed
  figure scrolls sideways, as a wide table does; Choose's thumbnails still shrink.
- **A note goes right of its k-mer only at a row's end** (#403), beneath it otherwise.
