## Decisions, and why

- **Text blocks side by side are one block** (#258), so `align`'s tests move a callout.
- **Workbench notes read the cached draft** (`useDraft`), not a prop through every tab.
- **An exam request sits under its row**, not also above the editor.
- **A decision marks the review stale**, not removed (#294).
- **After answering a changed question, its draft's review is asked once more**: only the server
  holds the earlier key (#297). Unchanged questions still ask nothing.
- **`align`: equal runs, then the same text anywhere, then position within a replace span**; a
  block that went from one end and one that came at the other are not an edit (#295).
- **The word diff is colourless**: struck-through ink-3 and underlined ink (#298, invariant 11).
- Left from the board: the search box; filters as selects; the bulk bar under the list.
- The dev database holds M4.8's submitted *Bubbles in a graph*; the walk waited for TPM to leave
  the queue, not for an empty one.
