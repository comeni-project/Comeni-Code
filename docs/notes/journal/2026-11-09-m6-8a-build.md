## Decisions made, and why

- **No mutation hook**: the spec said `useProblemAnswer` in `queries.ts`; the codebase writes with
  plain `sendJson` functions, so `sendAnswer` is one, in `api/problem.ts`.
- **The version memo is keyed by text and the kit object**, and `problems.forget()` clears it, so a
  test that swaps a kit (Kit is frozen: replaced in `registry.KITS`) sees a new version.
- **Callouts get anchors** (`callout-<index>`, the first of each title) so a verdict can scroll to
  the one it quotes; `Callout` takes an optional `anchor`.
- **First steps draws the problem too**, beyond the plan's files: a First steps node with a problem
  would otherwise draw nothing at its block.
- **Review fixes re-graded up**: a chosen file read whole before its size (#430), the download's URL
  revoked at once (#431, Safari) and the file input's invisible focus (#432) were labelled minor;
  each is what a learner meets, so each was fixed test-first.
