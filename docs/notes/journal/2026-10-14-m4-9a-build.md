## Decisions, and why

- **Verdicts compare with the strings** `"approved"`/`"changes"`, not `Verdict.Given`: mypy's
  comparison-overlap on the Literal-typed input; same values.
- **The review's questions carry hints**, for the board's *Hints the learner sees*.
- **Requests are ordered by the revision that was sent back**, which stays put while the author
  edits.
- Ruled with the final review: only the sender's requests reach the author (one approval is
  enough in v1); a contributing reviewer may still read the review and answer, as in M4.5, but not
  judge; a try and an exam question never share an id (CS08xx keeps them apart); an old `rejected`
  event shows no requests, as nothing showed it before.
- A test run died with exit 137 when the Compose containers were killed; restarted, not the code.
