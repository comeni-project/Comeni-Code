## Decisions, and why

The spec holds them with what was rejected (M4F.1–M4F.6). With the operator: a timer plus a
follow at once on a merge (A); a Studio route for the index, not a health line (A). **The shape
changed twice in conversation**: the agent's case-by-case design was "really hard to follow and
complex for no reason", so it became one reconciler; and the operator did not want the manual
rebuild as a second path ("dead code on live"), so it became a source behind one interface, picked
by a factory — one method for everything.

## Traps

- **tarfile's `data` filter strips a leading `/` instead of refusing it**: check member names
  yourself, and read the root from what was unpacked, not from the names.
- **`transaction.on_commit` is not robust by default**: a callback that raises after the commit
  turns a saved change into a 500. Pass `robust=True` when the callback is a nudge.
- **A plan's code blocks lose their indentation** when pasted from a nested list: check that
  methods land inside their class.
