  by hand in each layer, plus a real bug. All of it is fixed on `refactor/m4-1-3-before-exams`

## Decisions, and why

- **The record reader shares mechanics, not rules.** A declarative table was the first idea. It
  was rejected because the parsers' ordered, conditional rules would turn that table into a small
  language. The schema tests, which pin every message and line, passed unedited.
- **`Node.blocks` is a plain property**, not cached. `functools` is not on code-schema's purity
  allowlist, and a body is a few kilobytes.
- **An error answer that is not JSON reports its status** (`HTTP 502` from nginx while the API is
  down), on every page. Health keeps its own rule: any status but 200 and 503 is shown by number.
- **The spec overstated one risk.** An unknown stored block kind was never drawn as a callout:
  Pydantic's `kind` `Literal` already refused it. The codec now makes that refusal deliberate, and
  the spec says so.
