## How this machine is set up

- **Node is 22 here; the web app needs 24.** Run web commands through a Docker wrapper, one
  command per call. A `sh -c "…"` script is refused by the harness's removal check.

  ```
  docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp \
    -v "$PWD":/repo -w /repo/apps/web node:24-alpine npm test
  ```

## Traps

- **Never pipe a check into `tail` or `grep` and trust the exit status.** Use
  `gh pr checks --watch > log; rc=$?`.
- **The purity guard allows only declared imports in `packages/`.** `functools`, for example, is
  not on code-schema's list. Widening the list is a reviewed decision.
- **`code_schema`'s messages, codes, lines and order are pinned by tests.** Treat a test you have to
  edit there as a behaviour change, and say so.
